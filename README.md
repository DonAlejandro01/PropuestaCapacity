# Proyecto Capacity Planning PHH

El enfoque de este proyecto sera solucionar y mejorar la experiencia del usuario en poder revisar su horario tanto diario como mensual. Esto debido a que en la actualidad los turnos se ven en una matriz poco amigable y facil de perderser. 


## Criterios de aceptacion

- Main minimalista
- Adaptable a movil
- Visualizacion personal del horario
- Visualizacion del grupo de trabajo
- Incluir horario directo en calendario google
- Boton que redirecciones a capacitacion cuando un funcionario tenga un curso pendiente
